# Remaining Work Index

Purpose: route agents to unresolved actionable work by workflow profile.

Use this file when meaningful work stops with remaining breakage, missing validation, blocked context, or follow-up inside the same ownership slice.

## Trackers

- Core registration: `.agents/references/remaining-work-core-registration.md`
- Fused ops: `.agents/references/remaining-work-fused-ops.md`
- Entrypoints: `.agents/references/remaining-work-entrypoints.md`

When a tracked item is resolved, mark it resolved here or in the profile tracker and record the completed fix in the matching recent-changes log.
